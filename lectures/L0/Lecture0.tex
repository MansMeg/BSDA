\section{Course information}
\frame{\sectionpage}

\begin{frame}{Course information}
The aims of this course are that, after this course you should:\\[3mm]\pause
\begin{enumerate}
\item have knowledge in basic concepts, philosophy, and perspectives in Bayesian Statistics,\pause
\item derive posterior distributions in simple situations,\pause
\item derive and use predictive distributions,\pause
\item identify and formulate Bayesian probabilistic models for analysis and predictions,\pause
\item estimate models using contemporary (state-of-the-art) computer-based methods for posterior approximations, \pause
\item understand and use basic principles for decisions under uncertainty, \pause
\item have knowledge about and be able to use Bayesian methods for model comparisons,\pause
\item be able to critically evaluate Bayesian methods,\pause
\item report, orally and in writing, a Bayesian statistical analysis\pause
\end{enumerate}

\end{frame}

\begin{frame}{LLM use and assignment integrity}

\begin{itemize}
\item \uured{New this year!} You may use LLMs like fellow students: to learn, ask for explanations, and get feedback.\pause
\item LLMs may not produce submitted solutions.\pause
\item You must be able to explain every part of your submitted work orally.\pause
\item LLMs are not allowed at all for the oral exam questions.\pause

\section{Examination}
\frame{\sectionpage}


\begin{frame}{Examination}

\begin{enumerate}
\item To pass (G): All labs, oral exams, mini-project, and project review need to be passed\pause
\item To pass with distinction (VG): 7/10 VG points\pause
\item If everything is correct in an assignment (>90\%), 1 VG point is awarded \emph{on the first submission deadline}.\pause
\item Assignment VG points require passing the oral exam for that assignment.\pause
\item The mini-project is worth 2 VG-points (if it is passed with distinction).
\item Ph.D. students: I suggest you get VG to pass the course. Make the project a potential paper.
\item Reassesment of grades (supply form to course admin)
\item Failing the course: You will need to redo all assignments and mini-project next year.
\item LLMs may be used for learning, explanations, and feedback, but \uured{not to produce submitted solutions}.
\end{enumerate}

\end{frame}
